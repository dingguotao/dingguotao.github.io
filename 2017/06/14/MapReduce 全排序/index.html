MapReduce 全排序

[TOC]

全排序是指，MapReduce输出的结果key全局有序。

默认情况下， MapReduce输出结果只能保证同一个reduce中key是有序的，但是无法保证全局有序。因此，通常有三种方法实现全局排序

  • 只使用一个Reduce进行排序

只有一个Reduce，MapReduce默认就是保证一个分区内有序。

  • 自定义分区函数，实现全局有序（要有经验）

自己根据处理数据key的分布，合理将key按照范围发送到对应的reduce

如key<100 的发送给reduce0

1000 <= key < 200的发送给reduce1

​ key >=2000的发送给reduce3

  • 使用TotalOrderPartition进行全排序

这种主要可以克服上述两个的不足：

  • 使用一个reduce，在数据量大的时候，容易造成OOM
  • 自定义分区函数实现全排序，出现数据倾斜的概率大

使用TotalOrderPartitioner全排序

MapReduce默认使用HashPartitioner来实现
